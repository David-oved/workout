# workOut

אפליקציית PWA אישית למעקב תזונה ואימונים בתהליך מאסה. עברית מלאה (RTL), דארק מוד, עיצוב Liquid Glass, מותאמת לאייפון.
כל הנתונים נשמרים מקומית על המכשיר (IndexedDB), בלי שרת ובלי התחברות.

## הוספה למסך הבית באייפון
1. לפתוח את הכתובת ב-Safari.
2. שיתוף ← "הוסף למסך הבית".

## פיתוח
```
npm install
npm run dev        # שרת פיתוח
npm run build      # בדיקת טיפוסים ובנייה ל-dist
npm run icons      # מייצר מחדש אייקונים ומסכי פתיחה מ-scripts/make-icons.mjs
```

## מערכת עדכונים
- בכל בנייה נכתב `version.json` לשורש האתר (גרסה, מזהה בנייה, מה חדש).
- האפליקציה בודקת אותו מהשרת בלי מטמון: בפתיחה, בכל חזרה לאפליקציה ובכל חצי שעה.
- כשיש גרסה חדשה מופיע באנר "עדכון זמין" עם כפתור. הנתונים לא נמחקים בעדכון.
- הגרסה והעדכון מופיעים גם בהגדרות.

**להוציא גרסה חדשה:** מעלים את `version` ב-`package.json`, מוסיפים שורות ל-`release-notes.json` תחת אותה גרסה, ועושים push ל-`main`. GitHub Actions בונה ומפרסם.

## מבנה
```
src/core      נתונים, חישובים, פעולות (actions) וגיבוי
src/screens   היום, הוספה, התקדמות, לוח שנה, הגדרות, גיליונות עריכה
src/ui        רכיבי UI (זכוכית, סרגל תחתון, גיליונות) ומצב UI
src/update    בדיקת עדכונים
src/ai        הכנה לחיבור AI בשלב 3 (כלים ומשק ספקים)
```

## שלבים
1. **שלב 1 (הגרסה הזו):** ליבה מלאה, עריכה ומחיקה, לוח אימונים פנימי, גיבוי, עדכונים.
2. **שלב 2:** סנכרון Google Calendar ופושים לתזכורות אימון.
3. **שלב 3:** חיבור AI.
